# Calculadora CNPJ ou PF

Calculadora do [Recebo de Fora](https://www.recebodefora.com.br): quanto sobra por mês pra quem recebe do
exterior, comparando pessoa física (Carnê-Leão) com CNPJ no Simples (Anexo III via fator R e Anexo V),
com a receita marcada como exportação de serviço.

No ar em https://calculadora.recebodefora.com.br

Página única, sem dependências. Números aproximados, tabelas de 2025. Antes de decidir, valide com um
contador especializado em exportação de serviços.
